# AI Resume Analyzer & Job Matcher

An AI-powered web application that analyzes resumes against job descriptions, identifies matching and missing skills, calculates resume and job-match scores, and generates personalized feedback using a locally running AI model.

**Project Status:** Work in Progress 🚧

## Overview

The AI Resume Analyzer & Job Matcher helps job seekers understand how their resumes align with specific job requirements.

Users can upload a resume, provide a job description, and receive an analysis containing matching skills, missing skills, resume scores, job-match percentages, and AI-generated improvement suggestions.

The project combines Java full-stack development with local AI integration.

## Features

* Resume upload and text analysis.
* Resume score calculation.
* Job-match percentage calculation.
* Matching skill identification.
* Missing skill identification.
* AI-generated resume feedback.
* Practical suggestions for improving job readiness.
* Analysis history stored in the database.

*Note: The analysis history interface and other planned features may still require further development and testing.*

## How It Works

1. The user uploads a resume.
2. The application extracts resume text.
3. The user provides a job description.
4. The backend identifies relevant skills in the resume and job description.
5. The application calculates a resume score and job-match percentage.
6. The local AI model generates feedback and improvement suggestions.
7. The analysis results are displayed on the frontend.

## Running the Project Locally

### Prerequisites

Install the following tools:

* Java Development Kit (JDK)
* Maven
* Node.js and npm
* Ollama

The project uses the Qwen3 4B model through Ollama.

### 1. Start Ollama

Install Ollama and download the model:

```bash
ollama pull qwen3:4b
```

Ensure Ollama is running locally.

### 2. Start the Backend

Open a terminal and navigate to the backend folder:

```bash
cd backend
```

Start Spring Boot using Maven:

```bash
mvn spring-boot:run
```

The backend is expected to run on port `8080` with the current configuration.

### 3. Start the Frontend

Open another terminal and navigate to the frontend folder:

```bash
cd frontend
```

Install the frontend dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in the terminal. With the default Vite configuration, this is usually:

```text
http://localhost:5173
```

*Note: The instructions above assume the existing project configuration uses these ports and commands. Additional environment configuration may be required.*
